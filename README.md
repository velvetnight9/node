# Архив страницы-заглушки

Состав проверен 19.10.2026: `index_zaglushka.zip` — архив статической страницы.
Репозиторий не содержит RemnaNode/Xray, конфигурации панели, credentials нод
или готового автоматического установщика серверов.

Перед использованием распаковать архив в отдельную папку и проверить HTML,
локальные assets и внешние ссылки. Публиковать только через существующий
web server после backup его конфигурации. Не заменять общий nginx/Caddy config
примером и не открывать дополнительные порты без плана установки.

Автоматическая настройка нод разрабатывается отдельно. Инструкцию её установки
и проверки следует добавить после завершения и проверки самого скрипта.
Данные частной инфраструктуры и секреты в этот публичный репозиторий не добавлять.
